# 💻 Página Profissional — Portfólio Pessoal

Projeto desenvolvido para criar uma **página profissional e responsiva**, reunindo informações sobre minha trajetória, conhecimentos, experiências e projetos na área de tecnologia.

A aplicação foi desenvolvida com foco em **HTML e CSS**, explorando conceitos de estruturação de páginas, navegação entre conteúdos, formulários e organização visual.

## 📌 Sobre o Projeto

A página funciona como uma apresentação profissional, permitindo que o visitante conheça minha trajetória e tenha acesso a diferentes conteúdos através de um menu de navegação.

O projeto conta com as seguintes seções:

* **Sobre** — apresentação pessoal e informações sobre minha trajetória.
* **Currículo** — informações relacionadas à formação acadêmica, experiências profissionais, conhecimentos e qualificações.
* **Blog** — conteúdo explicativo sobre o conceito de **Flexbox**, apresentando seus principais recursos e aplicações.
* **Exemplos de Flexbox** — demonstrações visuais do funcionamento do Flexbox através de imagens e exemplos práticos.
* **Contato** — formulário para envio de informações pelo visitante.
* **Página de Sucesso** — após o preenchimento do formulário, o usuário é direcionado para uma página de confirmação, contendo uma opção para retornar à página inicial.

## 🧭 Estrutura de Navegação

```text
Página Inicial
│
├── Sobre
│
├── Currículo
│
├── Blog
│   └── Flexbox
│
├── Exemplos
│   └── Demonstrações de Flexbox
│
└── Contato
    └── Formulário
        └── Página de Sucesso
            └── Retornar ao Index
```

## 🛠️ Tecnologias Utilizadas

* **HTML5** — estrutura e organização das páginas.
* **CSS3** — estilização, layout e responsividade.
* **Flexbox** — construção e organização dos elementos da interface.
* **Iframe** — utilização para apresentar diferentes conteúdos dentro da página principal.
* **Formulários HTML** — coleta das informações enviadas pelo usuário.

## 🎯 Objetivos

O projeto foi desenvolvido com os seguintes objetivos:

* Praticar a criação de páginas utilizando **HTML5 e CSS3**;
* Aplicar conceitos de **Flexbox** na construção dos layouts;
* Desenvolver uma estrutura de navegação entre diferentes conteúdos;
* Criar e estilizar formulários;
* Trabalhar com diferentes páginas HTML integradas à página principal;
* Desenvolver uma apresentação profissional para utilização como portfólio;
* Praticar organização e estruturação de um projeto web.

## 📖 Conteúdo sobre Flexbox

Uma das partes do projeto é dedicada ao estudo do **CSS Flexbox**, apresentando conceitos como:

* `display: flex`
* `flex-direction`
* `justify-content`
* `align-items`
* `flex-wrap`
* `gap`
* `flex`
* Alinhamento e distribuição de elementos

Além da explicação teórica, o projeto apresenta exemplos visuais para demonstrar como esses recursos funcionam na prática.

## 📬 Formulário de Contato

A seção de contato possui um formulário destinado ao envio de informações do visitante.

Após o preenchimento e envio, o usuário é direcionado para uma **página de sucesso**, confirmando a conclusão da ação.

A página de sucesso também possui um botão que permite retornar ao `index.html`.
